# 工具操作层规范（编辑 tcl / 工具脚本时适用）

> 本目录是**工具操作层**。核心原则（ADR 0020）：**方法自由、证据可追溯、验收不可自改**。`hw/scripts/ops.yaml` 是参考清单（非强制白名单）。

## tcl 脚本两段分离（ADR 0020 补充）
工具脚本（如 run_sim.tcl）按职责分两段，修改自由度不同：

| 段 | 职责 | 修改自由度 |
| --- | --- | --- |
| **驱动段** | 建工程、启仿真、收集日志（搬运工，不参与验证计划设计） | agent 可自由改造（方法自由） |
| **汇总判读段** | 汇总各用例结果、生成 SUMMARY、判定 PASS 的口径 | **属验收口径——改动需用户审核，与验证计划（hw/verif/）同级** |

写/改 tcl 时自我定位：动的是哪一段？动汇总判读段（改 PASS 判定条件、改纳入计数的用例范围）= 改验收标准，必须停下来报用户审核。验证计划层管"测什么、怎么判对错"；本段管"哪些结果被算进 PASS"——两者同级受保护。

## 机读契约：SUMMARY 是"反馈格式"，不是"信任来源"
任何工具脚本，日志末尾必须输出：
```
=== SUMMARY ===
RESULT: PASS | FAIL
RUN_ID: <本次运行标识>
<KEY>: <value>   # 关键数值（用例计数、错误计数、种子等）
```
- **SUMMARY 用于快速定位结果**，由真实结果推导；它本身不构成 gate 证据
- SUMMARY 可信的两个前提（ADR 0020 补充）：**(a) 运行身份真实**（本次 run_id 的完整运行，非旧报告/未完成任务）；**(b) 判定口径未变**（汇总判读段的 PASS 口径与已批准验收标准一致，改动需审核）
- gate 证据还须核对：**运行确已完成 + 输入身份（git hash/参数/种子/run_id）+ 实际检查范围 + 原始报告 + 通过条件**
- 缺失 SUMMARY → fail-closed 视为结果未知，不得"没报错就当成功"
- 退出码：**0=PASS，非 0=FAIL**（统一口径）；无法确定结果时返回非 0（ADR 0013）。执行类 op 如需区分"执行成功"与"验证通过"，在 SUMMARY 里用不同字段表达，不得靠退出码混用
- **全脚本一致**：所有 op（含 verification 类如 check_ports）都要有明确退出码与 SUMMARY 段，不允许"某脚本例外"

## 证据选择：run_id 绑定，不回退"最新一份"
- 每次启动确定一个 `run_id` 与明确的输出路径，**后续只消费该路径**
- 通配符（如 `logs/sim_*_*.log`）**只用于浏览，不用于正式证据选择**——并行/不同种子/debug-release 会串用
- 找不到本次 run 的结果 → 判未知并阻塞，**不能回退到"最新一份 PASS"**
- ops.yaml 的 `result_glob` 仅供定位参考；正式证据以 run_id 具体路径为准

## 长任务三态
综合/实现/大回归用后台运行 + 轮询，并明确：**完成 / 超时 / 取消**。超时或摘要缺失 → gate 阻塞，不视为通过。

## 脚本写法约定（新增/修改时）
- **kind 意识**：执行类（建工程/综合，改变世界）vs 检查类（只读判定）——gate 只接受检查类输出作证据（ADR 0010）
- **可移植**：脚本是项目完成后的可移植资产——参数（器件/版本）集中在文件头，换项目改参数即可重建

## 源文件外置工程（铁律 1）
- `.xpr` 由脚本重建，不入库；**禁止** `import_files` / 勾选 *Copy sources into project*
- 源文件只通过 filelist 引用：`read_filelist` 读取 `rtl.f` / `verif.f`

## 关于 MCP（当前取舍，非技术禁令）
- **暂不引入 MCP server**（含自建 Vivado MCP）。理由：当前本地脚本 + Bash + SUMMARY 已够用，新增服务收益不足；且 MCP 工具常驻上下文有污染成本（同 ADR 0007 对 amd-doc-search 的考量）。这是**当下的取舍**，若未来出现收益明确的场景可重估——不要把它当成"MCP 天生不适合"的绝对结论（ADR 0019）。

## filelist 解析契约（ADR 0013，已踩过的坑）
- 读取每行后**先剥离 `#` 行尾注释再 trim**（否则注释被拼进路径导致 add_files 失败——评审 #5 实锤 bug）
- 空行跳过；路径相对仓库根；`-f` 嵌套仅用于 verif.f 引用 rtl.f

## 版本与证据（ADR 0012）
- 脚本开头用 `version` 等命令采集工具版本，写入运行产物（证据绑定：git hash + 工具版本 + run ID）
- 运行产物按 `板卡 / debug|release / run_id` 隔离，不得覆盖旧报告
