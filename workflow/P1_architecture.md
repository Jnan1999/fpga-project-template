# P1 系统架构（System Architecture）

> 阶段目标：把 SRS 落到具体的系统结构——模块划分、逐层数据流/控制流、实际存在的处理器/FPGA 职责边界、时钟复位架构，以及适用的寄存器/地址映射。纯 FPGA 项目不虚构 PS/PL 分工。
> 出口后系统的"骨架"冻结，后续阶段只在骨架内工作。

## 1. 入口条件
- G1 通过：`project.yaml` 中 `P0.status: done`

## 2. Agent 输入（必读）
> 以下清单为**最低要求**（下界非上界）。

| 输入 | 路径 |
| --- | --- |
| 需求基线 | `docs/00_project/00-02_SRS`、`00-03_RTM`、已确认的 `00-00_需求确认清单.md` |
| 参考资料 | `docs/refs/`（datasheet 接口时序章节重点读） |

## 3. Agent 任务
1. 从 P0 已确认的**实际系统边界**出发，复核每层（主机/设备、板卡/外设、处理器/FPGA〔若有〕、FPGA 内部，或项目自定义层）是否适用；在 `01-01_系统架构设计_HLD.md` 画控制流和数据流，标明发起方/目标、实例和责任。不存在的层写“不适用＋原因”，不得复制示例拓扑。
   - 模块划分表（模块/职责/接口/时钟域/关键参数）；模块粒度按可独立验证划分。
   - 仅在有处理器/软核时画处理器与 FPGA 逻辑职责划分；纯 FPGA 改画主机接口/外设控制/内部逻辑的责任边界。
   - 数据流（位宽、格式、各级吞吐、反压）与实际缓存路径；FIFO、DMA、DDR、零拷贝只在存在且确认后纳入设计。
   - 资源预算表（各模块 LUT/FF/BRAM/DSP 估算，总量 ≤ 80%）；是否调整原有验收上限须单独经用户评审，不因本次分层模板更新自动改变。
2. 生成 `01-02_接口控制文档_ICD.md`：按适用层登记每个边界的协议、地址空间、端点方向、时钟/CDC、错误反馈；用端到端业务路径交叉检查，不把网络命令码、器件地址、IP 窗口和业务寄存器混用。优先复用适用的成熟标准；AXI/DMA 只在实际设计采用时列入。
3. 当存在处理器/主机可访问的 FPGA 寄存器或独立 IP 地址空间时，生成 `01-03_寄存器映射规格.md`：逐地址空间列基址/偏移、权限、复位值、位域及访问规则；无此类映射时记录不适用及替代配置途径。P0 候选表不直接视为冻结结果。
4. 生成 `01-04_时钟与复位架构.md`：时钟树、复位树、**CDC 逐条清单**（每条含同步方式与验证方法）。
5. 有 PS/嵌入式控制软件才生成适用的 `01-05_PS软件架构设计.md`；否则标注不适用并描述实际固件/FPGA 命令处理归属，勿虚构裸机、lwIP、DDR 或 DMA。
6. **登记 `project.yaml`**：
   - `interfaces:` 登记实际需追踪的接口（name/from/to/protocol/width/clock/icd_section，`frozen: false`）；ICD 中明确物理、软件与内部接口的关联。
   - `modules:` 登记全部实际模块（status: design，rtl/tb/lld 路径按命名约定填）。
   - `registers.base:` 仅在该单基址确为实际业务寄存器窗口时核定；有多窗口或不适用时先按接口契约评审数据结构，不填写虚构地址。

## 4. 验证命令
本阶段无代码命令。完工自查项：
- [ ] RTM 每条功能需求在 HLD 模块划分表中有承接模块（逐条对照）
- [ ] `project.yaml` interfaces 每条与 ICD 章节一一对应，且字段完整
- [ ] 每条跨时钟域路径在 01-04 CDC 清单中有行
- [ ] ICD 对每个适用层有接口清单，省略层有原因；同一业务命令的跨层地址空间/端点与 HLD 一致
- [ ] 实际采用的寄存器/独立 IP 窗口与 ICD 对应章节一致（地址/宽度/错误行为）；若无映射，有明确 N/A 与替代途径
- [ ] 资源预算总量 ≤ 80%，BRAM/DSP 不超器件总量；如项目确需不同上限，先经用户评审变更验收口径

## 5. 出口标准（G2 architecture review）
- 用户评审 HLD/ICD/寄存器映射通过（重点：接口选型是否复用成熟标准、模块划分是否合理）
- 用户确认后更新 `project.yaml`：`P1.status: done`、`P2.status: in_progress`、`current_phase: P2`

## 6. 常见失败模式
| 失败模式 | 规避 |
| --- | --- |
| 不辨平台类型，把 PS/PL 或 AXI/DMA 套到纯 FPGA 板卡 | 沿 P0 实际边界裁剪模板，记录不适用层与替代链路 |
| 自造接口协议而不复用适用的成熟标准 | 在实际平台可用且满足需求时优先成熟标准；自定义须写明理由并经用户确认 |
| 寄存器映射与 ICD 不一致 | 两份文档同一次提交修改，互相引用章节号 |
| 时钟树缺 CDC 分析 | 每条跨域路径进 01-04 清单，注明同步方式；禁止多 bit 裸跨域 |
| 模块划分过细（几十个小模块）或过粗（一个模块做所有事） | 按"可独立验证、接口清晰"划分；拿不准列方案问用户 |
| 资源预算拍脑袋 | FIFO/缓冲按最坏反压计算 BRAM；乘加按并行度算 DSP |
