# host —— 上位机与自动化测试（Python）

## 目录约定
| 目录 | 内容 |
| --- | --- |
| python/ | 上位机：命令下发、UDP 接收、数据解析、界面（如有） |
| golden_model/ | 黄金参考模型：算法的 Python 定点实现，作为 RTL/板载结果的比对基准 |
| scripts/ | 自动化测试：激励生成、数据采集、三路比对、扫眼、吞吐/丢包测试、绘图 |
| data/ | 采集数据、测试向量（大文件用 git-lfs/外部存储） |

## 数据正确性核对（标准动作）
1. 分别接收并保存：板上原始数据、板上解调结果
2. 用 golden_model 对原始数据计算期望结果
3. scripts 自动做三路比对：期望 vs 原始一致性、期望 vs 板载结果，输出逐点差异与统计
4. 比对结论写入 docs/05_bringup/05-04_板级测试报告.md

## 建议
- 用 requirements.txt 固定依赖；脚本支持命令行参数化（IP/端口/帧数/用例名）
- 测试脚本与 docs/03 测试矩阵、docs/05 板级用例编号对应
