## 关键实证（本机 Vivado 2021.1）

- `uv run python scripts/check_gate.py exit G3 --slow`：
  check_ports（pulse_gen 三件套一致）→ check_elab.tcl（synth_design -rtl + report_methodology，
  SUMMARY 落 `logs/elab_<run_id>.log`）→ evidence 核对 GIT_HASH==HEAD + ERRORS=0 +
  METHODOLOGY_CRITICAL=0 → **RESULT: PASS，退出码 0**。证据绑定链第一次完整跑通。
- SUMMARY 字段按 logs/README 新约定：必带 RUN_ID/GIT_HASH/TOOL_VERSION，数值用独立 KEY 行。

## 发现的问题与处理

1. **Vivado 间歇读不到自身安装脚本**（D:\XilinxTools\...\rt\*.tcl，每次不同文件，重跑即过）。
   杀毒/索引软件扫描干扰的典型症状，非模板问题。**建议用户把 `D:\XilinxTools` 加入
   Windows Defender 排除目录**。
2. **ADR 0020 我自己的误判**：评审说 `-coverage all`，我当时答"仓库从无此项"——错，
   它就在 run_sim.tcl:66。已更正 ADR 并在该处标【待核实】。教训记入 ADR：否决评审意见前
   必须先仓库实证。
3. **check_ports 缺 SUMMARY**：ops.yaml 0.3.0 承诺的字段实际没实现，本批补上（含
   PARSE_ERRORS 计数；解析失败从 traceback 改为逐对 fail-closed 计数）。
4. **GIT_HASH 绑定边界**：只绑 HEAD 提交，识别不了脏工作区。后续批次评估加
   `git status --porcelain` 检查。
