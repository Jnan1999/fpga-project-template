# ADR 0007：暂不启用 amd-doc-search MCP（防上下文污染）

- 日期：2026-10-15
- 状态：已确认（修订 ADR 0002 的"首选层"实施时机）

## 背景
ADR 0002 确定手册检索用"三层方案"，其中首选层是 AMD 官方 amd-doc-search MCP server。但用户随后明确：**暂不启用该 MCP**，原因是 MCP 会把一批工具注入 Agent 的上下文（tool 定义占用上下文窗口、可能被模型误调用），造成上下文污染。

## 决策
- **当前不启用 amd-doc-search MCP**，手册检索退化为两层：
  1. 手册地图 `docs/refs/xilinx/`（决定"该查哪本哪章"）
  2. 提示词引用规范（兜底：引用须注明 UG号+章节+版本；未接 MCP 时 Agent 凭已知权威写法作答并**标注待核实**）
- amd-doc-search MCP 仅以**注释/文档形式保留**在 `.claude/README.md`，标注"默认不启用 + 启用方法 + 何时考虑启用"
- 未来若确需权威检索（如复杂原语/新 IP 配置、本地记忆不可靠时），再由用户显式启用

## 理由
- 上下文是稀缺资源；MCP 工具常驻会稀释有效上下文，且手册检索并非每次会话都需要
- 当前阶段（模板搭建 + 早期模块）手册引用频率低，提示词规范 + 手册地图已够用
- 保留 MCP 作为"可随时启用的备选"，不删除相关文档——决策可逆

## 后果
- `.claude/README.md`：MCP 部分改为"默认不启用"的注释/说明
- `docs/refs/xilinx/README.md`、`.claude/agents/rtl-engineer.md`：检索方式描述去掉"amd-doc-search MCP（首选）"的现行启用表述，改为"备选，默认不启用"
- 手册引用规范（注明 UG号+章节+版本、标注待核实）保留不变
