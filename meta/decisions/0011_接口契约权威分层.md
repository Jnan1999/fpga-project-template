# ADR 0011：接口契约的权威来源分层（机读契约独立）

- 日期：2026-10-15
- 状态：已确认
- 来源：外部评审#2

## 背景
P2 要求"LLD 与 interfaces 表信号级逐字一致"，但 project.yaml 的 interfaces 只有 name/from/to/protocol/width/clock/frozen，没有逐信号声明、参数、符号属性、复位/握手语义。检查器无法仅依据这份表执行所承诺的信号级检查。且"frozen: true"冻结的是一个可被继续修改的名称，而非具体版本内容。

## 决策
按权威来源分层，机读契约独立为 `contracts/interfaces.yaml`：
| 数据 | 权威来源 |
| --- | --- |
| 项目配置/模块索引/流程状态 | `project.yaml` |
| 信号/参数/接口语义（机读） | `contracts/interfaces.yaml` |
| 解释/图示/设计理由 | ICD / LLD（引用契约，不复制机读字段） |
| 执行状态与批准记录 | project.yaml + 验证证据 |

每条接口含：interface_version、端点、逐信号 ports{name,dir,width_expr,clock,reset}、parameters{name,default,range}、握手/背压/异常语义、cdc、frozen + frozen_at(git hash) + approved_by。
**冻结的是具体版本内容（含 git hash 摘要），不是一个名称。**

## 理由
- 单一事实来源：机读字段只在一处，ICD/LLD 引用而不复制，消除多副本漂移
- 信号级契约才能支撑 check_gate.py 的信号级比对（第二批）

## 后果
- 新建 contracts/README.md（权威分层）+ contracts/interfaces.yaml（占位结构）
- project.yaml 的 interfaces 降级为轻量索引
- check_gate.py 的信号级检查以 contracts/ 为准（第二批实现）
