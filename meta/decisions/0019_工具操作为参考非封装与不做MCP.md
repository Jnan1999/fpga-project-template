# ADR 0019：工具操作是"参考"而非"封装"，且暂不引入 Vivado MCP（修订 ADR 0017）

- 日期：2026-10-16
- 状态：已确认（修订 0017 的"op 白名单 + 铁律5 强制"定位；部分表述被 [ADR 0020](0020_方法自由证据可追溯验收不可自改.md) 修正）

## 背景
用户 clarifying：要少设计机械执行步骤，多给设计思路，相信大模型的判断力。具体地——
建工程这类低频、语法固定的操作，agent 看示例 tcl 即可自行生成/改造，**不值得做成 command/skill**；
复杂操作（时序分析等）后续才做成 skill。同时用户追问：ops.yaml 到底怎么起作用？SUMMARY 机读契约是什么？

## 关键澄清（本次对话明确的事实）
1. **ops.yaml 无强制力**：Claude Code 没有代码读它。它靠 CLAUDE.md 的指向被 agent 阅读，本质是"机器可读的操作说明书"。真正的强制只有 hooks（拦截）和 check_gate（事后验证）。
2. **SUMMARY 机读契约**：脚本日志末尾固定输出 `=== SUMMARY ===` 段（RESULT: PASS/FAIL + 关键数值）。对脚本作者是"必须打印"的责任；对 agent 是"只认这段、没有就 fail-closed"的判读约定。它让 agent 用稳定廉价的方式获得可信结论，不必逐行理解几百行日志。

## 决策
1. **ops.yaml 从"强制白名单"降级为"参考清单"**。agent 可据示例自行决定调用时机/参数，可改造或新写脚本。
2. **撤销铁律 5（禁止绕过 ops.yaml）**。原铁律 5 与"相信 agent 判断"冲突。CLAUDE.md 铁律回归 4 条（只列顺序与禁忌类），工具操作改为"工具操作"一节的参考说明。
3. **唯一保留的硬要求 = 机读契约**：任何工具脚本末尾必须输出 `=== SUMMARY ===` 段。这是低成本、高价值、不改变 agent 自由度的最小约束。
4. **自由度分级**（指导后续所有"要不要封装"的判断）：
   - ① 顺序与禁忌 → CLAUDE.md 铁律（硬）
   - ② 低频语法固定操作（建工程/仿真）→ 示例脚本 + 机读契约，agent 自由改造，**不封装**
   - ③ 复杂需方法论操作 → skill 候选（第三批起）：**时序收敛分析、CDC 审查、仿真失败归因、覆盖率收敛、寄存器表生成**
   - ④ 纯创意/分析 → 只给设计思路，完全放手
5. **暂不引入 Vivado MCP**（修正表述，评审 2026-10-16 / ADR 0020）：理由是**当前取舍**——本地脚本 + Bash + SUMMARY 已够用、新增服务收益不足，且 MCP 常驻上下文有污染成本（同 ADR 0007）。**不写"MCP 天生不适合批处理"这类绝对禁令**，以免未来为合理需求推翻整套原则。
6. **hooks 留作"编辑后自动校验"**（如改 RTL 后自动跑 check_ports），列入第三批，与 op 互补而非替代。

## 修正（ADR 0020）
- **自由度分级改按"风险"而非"语法复杂度"**：建工程脚本语法简单但影响大（改器件/顶层/约束即改变最终硬件）。更稳的分级——
  - **自由探索**：查资料、分析报告、提方案、试验执行方式
  - **结果可追溯**：仿真/综合/实现必须能定位具体输入与输出
  - **变更需批准**：接口、验收标准、时序例外、发布与硬件操作
- **"SUMMARY 是唯一硬要求"表述过强**，见 ADR 0020：SUMMARY 是反馈格式，不是信任来源。核心原则应为"方法自由、证据可追溯、验收不可自改"。

## 理由
- 用户的自由度理念是大模型协作的正确姿势：机械步骤交给示例，判断力留给模型
- 机读契约是"约束最小化 + 可靠性最大化"的平衡点：一条 SUMMARY 约定换来可信判读，不牺牲任何自由度
- MCP 的拒绝理由与 ADR 0007 一致，且自建 MCP 比官方 MCP 污染更重

## 后果
- CLAUDE.md：删铁律 5，加"工具操作"一节（参考定位 + 机读契约 + 长任务 + 可移植性 + 不封装不设 MCP）
- ops.yaml：ops_version → 0.2.0，重定位为参考清单，补 `result_glob` + `long_running`
- tcl-ops.md：op 契约段重写为"机读契约 + 写法约定 + 不做 MCP"
- rtl-engineer agent 定义：清除残留的铁律 5 引用
- ADR 0017 保留但标注被本 ADR 修订（op 五要素保留，"白名单/铁律5 强制"部分作废）
