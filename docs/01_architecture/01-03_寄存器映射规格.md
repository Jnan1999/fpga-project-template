# 01-03 寄存器映射规格（Register Map / Programming Guide）

> PS 与 PL 的软件接口合同。每个寄存器必须有：地址、名称、读写属性、复位值、位域定义、行为说明。驱动代码（sw/drivers）与本文档严格一致，建议由表格自动生成 C 头文件。

- 基地址（BASE）：0x________
- 地址步长：4 字节；访问宽度：32 bit；多字节字段注明字节序

## 2. 位域详细定义（每个寄存器一节，示例）

### 2.1 CTRL（0x04）
| 位 | 名称 | 权限 | 复位 | 说明 |
| --- | --- | --- | --- | --- |
| 0 | start | RW/自清零 | 0 | 写1启动单帧采集 |
| 1 | stream_en | RW | 0 | 连续上传使能 |
| 2 | stop | RW/自清零 | 0 | 写1停止 |
| 3 | self_test | RW/自清零 | 0 | 触发硬件自检 |
| 4 | soft_rst | RW/自清零 | 0 | 仅复位数据通路（不复位总线） |
| 31:5 | reserved | — | 0 | 保留，写0读0 |

### 2.2 STATUS（0x08）
| 位 | 名称 | 说明 |
| --- | --- | --- |
| 0 | busy | 采集进行中 |
| 1 | adc_lock | ADC 采样锁定 |
| 2 | mmcm_lock | 时钟锁定 |
| 3 | fifo_overflow | 发生过 FIFO 溢出（锁存，写 IRQ 清零） |
| 4 | frame_loss | 帧失步/丢帧（锁存） |
| 5 | dma_err | DMA 错误 |
| 其他 | — | 按模块扩展 |

### 2.3 DFT_CTRL（0x1C）
| 位 | 名称 | 说明 |
| --- | --- | --- |
| 0 | inject_en | 故障注入总开关 |
| 2:1 | inject_sel | 0=直通 1=延迟1拍 2=延迟2拍 3=随机反压 |
| 3 | obs_snapshot | 写1锁存内部状态快照 |
| 其他 | — | 发布版本必须可整体裁断（ENABLE_DFT=0） |

## 3. 统一错误码表
| 错误码 | 含义 | 触发条件 | 恢复动作 |
| --- | --- | --- | --- |
| 0x00 | 无错误 | — | — |
| 0x11 | ADC 未锁定 | 位序/码型校验失败 | 重新标定 IDELAY |
| 0x12 | FIFO 溢出 | 满写 | 停采→清计数→重启 |
| 0x13 | 帧失步 | 帧头/帧尾不匹配 | 重新同步 |
| 0x14 | DMA 错误 | DMA 超时/错误中断 | 复位 DMA |
| 0x21 | 非法命令 | 未知命令字 | 回错误应答 |

## 4. 访问规则
- 保留位：写 0 读 0；对只读寄存器写操作的行为：忽略且不产生总线错误（或按 AXI 响应约定）
- 自清零位：写完一个周期后硬件自动清零
- 锁存状态：错误发生后保持，直到软件写 1 清零；计数寄存器可读后清零或带独立清零位
- 所有统计计数器必须考虑回绕行为与位宽

## 5. 与驱动/验证的对应
- sw/drivers/xxx.h 中宏定义（地址、位掩码、错误码）必须与本表一致
- 验证用例必须遍历：全部寄存器读写、复位值、非法访问、锁存/清零行为
