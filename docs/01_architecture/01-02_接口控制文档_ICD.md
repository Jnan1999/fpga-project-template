## 2. ADC 数据接口（LVDS DDR）
- 2.1 引脚映射表：信号名、FPGA 引脚、IO 标准（LVDS_25/DIFF_*）、DCI
- 2.2 时钟与帧：DCO/frame clk 关系、DDR 上下沿位序、通道映射
- 2.3 时序参数：t_SUI/t_H、t_PD、t_SKEW、建立/保持裕量（给出数值与来源）
- 2.4 测试码：checkerboard / PN / ramp，预期结果与判定方法
- 2.5 IDELAY/IDELAYCTRL：参考时钟频率、tap 分辨率、扫眼范围、最佳窗口定义

## 3. SPI 配置接口
- 时钟极性/相位、位序、速率、CS 时序
- 寄存器读写序列（以 ADC 芯片手册为准，引用页码）
- 初始化序列表与校验（chip ID 期望值）

## 4. AXI-Lite 寄存器接口
- 时钟/复位、数据宽度、地址宽度、基地址
- 读写时序要求、错误访问行为（非法地址/错位宽/写只读）
- 寄存器清单见《01-03_寄存器映射规格》

## 5. AXI-Stream / DMA 数据接口
- 5.1 信号定义：TDATA/TVALID/TREADY/TLAST/TKEEP，位宽与字节序
- 5.2 握手规则：valid 置起后数据保持稳定；反压传播；TLAST 编码含义
- 5.3 DMA 配置：S2MM/MM2S、Scatter-Gather 开关、burst 长度、缓冲地址、中断
- 5.4 数据格式与字节序：大端/小端、128 bit 内多字段拼接（给出位域图）

## 6. 以太网 / UDP 接口
- 6.1 网络参数：MAC、IP、端口、网关、MTU
- 6.2 命令帧格式（上位机→板卡）
| 偏移 | 长度 | 字段 | 说明 |
| --- | --- | --- | --- |
| 0 | 2 | 帧头 magic | 0x____ |
| 2 | 1 | 命令字 | 见命令字表 |
| 3 | 2 | 帧序号 |  |
| 5 | N | 参数 |  |
| 末 | 2 | CRC/校验 |  |
- 6.3 数据帧格式（板卡→上位机）：帧头、帧计数、半帧/通道索引、负载、帧尾 magic
- 6.4 命令字表：命令码、参数、响应、超时、错误码
- 6.5 异常处理：序号不连续、校验失败、未知命令的响应规则
- 6.6 性能约定：在途帧数、分片、流控、心跳/watchdog

## 7. UART 调试接口
- 波特率、数据位、停止位、校验；日志等级与前缀规范；报警信息编码表

## 8. 外部触发/时钟接口
- 电平标准、频率精度、抖动要求、接入 BUFG/BUFGCTRL 方式
