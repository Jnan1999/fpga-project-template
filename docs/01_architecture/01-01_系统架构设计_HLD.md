## 3. 处理器 / FPGA 逻辑职责划分（如适用）

> 下表是 SoC 示例；纯 FPGA 项目改为“主机接口 / 外设控制 / FPGA 内部模块”的责任表，注明 PS 不适用，不要建立虚构的 PS↔PL 接口。
| 功能 | 放 PL 还是 PS | 理由 |
| --- | --- | --- |
| 高速采样/接口时序 | PL | 确定性时序、并行 |
| 数据预处理/算法 | PL | 吞吐、延迟 |
| 帧打包/DMA 控制 | PL | 流式 |
| 命令解析/协议栈 | PS | 灵活、易迭代 |
| 数据缓存/调度 | PS DDR | 容量大 |
| 业务逻辑/上位机交互 | PS/PC | 可快速迭代 |

## 4. PL 模块划分与层次
| 模块 | 职责 | 主要接口 | 时钟域 | 关键参数 | 对应 LLD |

> 顶层只做例化与互连，不写业务逻辑；模块间一律走标准握手（AXIS/valid-ready），禁止裸 valid 无反压。

## 5. 数据流设计（Data Flow）
- 5.1 数据通路：数据位宽、定点格式（Qm.n）、各级吞吐、反压传播路径
- 5.2 缓存策略：按实际路径列 FPGA 内 FIFO / 外部 SRAM/DDR / DMA（如有），计算深度、回卷、帧边界和最坏反压。
- 5.3 如有处理器 DMA/网络零拷贝：明确缓冲所有权、在途帧数、cache 一致性；否则标不适用。
- 5.4 数据帧格式（概要，详见 ICD）：帧头、序号、负载、校验、帧尾

## 6. 控制流设计（Control Flow）
- 命令字表（启动/停止/单帧/连续/参数配置/自检）、执行状态机、命令-应答关系
- 中断设计：DMA 完成、错误、数据量阈值；中断优先级与合并
- 工作模式：空闲/采集/连续上传/调试（DFT）/自检，状态转移图
