# docs/06_review/decisions/ —— 项目级 ADR

> 评审#10 / ADR 0015：**模板演进与项目演进分离**。

## 与 meta/decisions/ 的区别

| 目录 | 记录什么 | 归属 |
| --- | --- | --- |
| `meta/decisions/` | **模板自身**的架构决策（为什么这样设计骨架/workflow/agent） | 模板仓库，跨项目共享 |
| `docs/06_review/decisions/`（本目录） | **当前项目**的架构决策（为什么这个模块这么设计、为什么选这个接口） | 衍生项目，随项目走 |

衍生项目的架构决策（模块选型、接口权衡、算法选择、资源取舍）记录在**本目录**，
格式同 meta 的 ADR（日期/状态/背景/决策/理由/后果），编号从 0001 起。

## 版本归属（三者不混为一个版本号）
- **模板版本**：本模板骨架的版本，记在 `project.yaml` 的 `template_version`
- **契约版本**：接口/规范结构的版本，随 `contracts/interfaces.yaml` 演进
- **硬件设计版本**：比特流/RTL 的版本，用 git hash + USR_ACCESS 追溯

## 模板升级
模板升级时，不自动覆盖项目已批准的规则；形成**差异与迁移记录**（哪个模板版本 → 哪个，改了什么，项目需不需要跟进）。
