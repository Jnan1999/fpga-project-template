# 04-01 时序约束策略（Constraints Strategy）

> 约束文件在架构阶段就规划，而不是综合不过才补。约束分文件管理（时钟/接口/CDC/物理），每条约束注明依据；所有异步关系必须显式声明，禁止“让工具自己猜”。

## 1. 约束文件划分（hw/constraints/）
| 文件 | 内容 |
| --- | --- |
| common_timing.xdc | 主时钟、生成时钟、不确定度 |
| adc_input.xdc | ADC 随路源同步输入延迟 |
| eth_io.xdc | 网口相关 IO/接口 |
| cdc_constraints.xdc | 跨时钟域 false_path / max_delay / clock_groups |
| physical.xdc | 管脚、电平标准、上下拉、驱动强度 |
| timing_exception.xdc | 多周期路径、虚假路径（逐条注明理由） |

## 2. 时钟约束
| 时钟 | 约束 | 周期/频率 | 不确定度 |
| --- | --- | --- | --- |
| 系统时钟 | create_clock | __ ns（__ MHz） | setup -0.30 ns |
| ADC DCO | create_clock（源同步） | 4 ns（250 MHz） | 按测量 |
| MMCM 输出 | create_generated_clock |  |  |
| 网络时钟 | （IP 自动生成） | 125 MHz |  |

## 3. IO 约束
- 输入：set_input_delay -clock adc_clk -max/-min，数值来自 ADC 手册（t_PD/t_SKEW）与板级走线
- 输出：set_output_delay（若有同步输出）
- 管脚：封装引脚、IO 标准（如 LVDS_25、DIFF_SSTL12）、DCI、驱动/压摆率

## 4. CDC 约束（与 01-04 CDC 清单一一对应）
- 异步 FIFO 两端：set_clock_groups -asynchronous 或显式约束
- 单 bit 握手/脉冲：set_max_delay -datapath_only
- 静态配置（复位后不变）：set_false_path（写明理由，禁止滥用）

## 5. 时序例外审查
- 每条 multicycle/false_path 必须有：编号、理由、设计者、评审人；评审时逐条检查
- 禁止对“不想收敛”的路径加 false_path 蒙混

## 6. 收敛策略（资源/时序）
- 高扇出：复制寄存器（max_fanout 或手动复制）
- 关键路径：加流水级、重定时、DSP/BRAM 映射、物理优化策略（Explore/AggressiveExplore）
- 必要时 pblock 固定关键模块（注明触发原因与时钟区域）
- 保留多版本策略的量化对比（WNS/WHS/TNS/资源）

## 7. 约束自查清单

- [ ] 所有 IO 有时序约束；CDC 与 01-04 清单完全对应
- [ ] report_clock_interaction / report_cdc 无未处理项
