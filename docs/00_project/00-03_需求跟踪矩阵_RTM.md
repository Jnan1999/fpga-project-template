# 00-03 需求跟踪矩阵（RTM, Requirements Traceability Matrix）

> 用途：保证每条需求“有人设计、有人验证、结果可查”，防止需求遗漏和无效测试。需求/设计/用例任何一处变更，都要回查本表。
>
> 维护规则：
> - 需求 ID 与 SRS 完全一致；设计章节对应 HLD/LLD；验证用例对应 Vplan/测试矩阵；板级用例对应硬件测试方案。
> - 状态取值：通过 PASS / 失败 FAIL / 阻塞 BLOCK / 未开始 TODO / 豁免 WAIVER（须写明理由与批准人）。
