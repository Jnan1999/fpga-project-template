# 03-02 测试矩阵（Test Matrix）

> 用例设计方法：输入空间地图 → 等价类划分 → 边界值三点法（边界内/边界上/边界外）→ 单维 → 多维组合 → 异常与压力。每行一个用例，标明覆盖的验证点，跑完后回填结果，用于覆盖率闭环。

## 1. 用例命名与分级
- 命名：tb_<模块>_<序号>_<场景>，如 tb_peak_007_cross_tile
- 分级：Smoke（冒烟）/ Regression（回归）/ Full（全量）
