# 05-03 调试记录与缺陷台账（Debug Log & Issue Tracker）

> 每一个上板/仿真问题都记录：现象、最小复现、定位过程、根因、修复、验证。这份台账是“错误模式库”的来源，也是面试中证明工程深度的素材。

## 1. 问题记录模板
### BUG-编号：简述（如：跨 tile 峰值处偶发数据气泡）
- 发现阶段：模块仿真 / 系统仿真 / 板级
- 环境：版本 commit、场景、激励、出现概率（必现/偶发 __%）
- 现象：观测到的具体错误（数值、信号、日志、截图）
- 最小复现：用例 ID / 种子 / 操作步骤（做到可一键复现）
- 定位过程：
  - 假设 1 → 验证手段 → 结论（排除/确认）
  - 假设 2 → …
- 根因：（如 CDC 多 bit 未同步 / FIFO 水位临界 / 位宽符号位 / 时序裕量）
- 修复：改了哪个文件、怎么改、为什么
- 验证：新增用例、回归结果、覆盖率变化
- 预防：该类问题的检查规则（可加入断言/DFT/Agent 检查清单）
- 经验归类：CDC / 位宽 / 反压 / 复位 / 时序 / 协议 / 软件
