# 05-02 硬件测试方案（Hardware Test Specification）

> 板级验收的正式用例集，每条需求（RTM）至少对应一条板级用例。用例编号 BT-<域>-序号，与 Bring-up 步骤关联。

- 板卡/器件、固件版本、上位机版本、仪器清单、连线拓扑、供电与温湿度条件

## 3. 数据记录与判定
- 每个用例保存：原始数据、解析结果、串口日志、截图/波形、时间、测试人
- 判定规则：定量项必须满足指标并留余量；定性项必须可重复复现
- 失败处理：记录缺陷单（见 05-03），修复后做回归并评估是否影响其他用例

## 4. 回归策略
- 硬件/固件每次变更后：Smoke 板级用例（B2/B3/B5/B7）
- 版本发布前：全部用例 + 长稳
